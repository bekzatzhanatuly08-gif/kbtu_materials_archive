# Правила доступа

Согласованные правила работы сервиса. По ним настраивается Row Level Security (RLS) в Supabase.
Все правила проверяются в самой базе, а не только на сайте: публичный ключ Supabase виден любому, поэтому защита держится на RLS.

## Роли

| Роль | Кто это |
|---|---|
| Гость | не вошёл в систему |
| Студент | вошёл с почтой `@kbtu.kz` |
| Модератор | студент, которому админ выдал роль `moderator` |
| Админ | владелец проекта |

## Регистрация и профиль

- Зарегистрироваться можно только с почтой `@kbtu.kz`. Проверка на уровне базы, не только в форме.
- Профиль создаётся автоматически при регистрации.
- Студент может менять в своём профиле имя, специальность и курс.
- Роль (`role`) меняет только админ. Студент не может поставить себе `moderator` или `admin`.

## Каталог

- Каталог дисциплин (школы, специальности, предметы) видят все, включая гостей.
- Менять каталог может только админ.

## Материалы

- Материалы видят только вошедшие студенты. Гости материалы не видят.
- Опубликованные (`published`) материалы видят все студенты.
- Материалы на проверке (`pending`), отклонённые (`rejected`) и скрытые (`hidden`) видят только автор и модераторы.
- Новый материал всегда создаётся со статусом `pending`. Студент не может сам поставить `published` и обойти ИИ-проверку.
- Автор может редактировать свой материал. После редактирования материал снова получает статус `pending` и уходит на ИИ-проверку.
- Автор может удалить свой материал.
- Модератор может скрыть любой материал и поставить значок «проверено».
- Файлы материала видны тем же, кто видит сам материал.

## Лайки

- Все студенты видят, кто именно поставил лайк, и общее количество.
- Ставить и убирать лайк можно только от своего имени.

## Комментарии

- Комментарии к опубликованным материалам видят все студенты.
- Писать комментарии можно только от своего имени.
- Редактировать свой комментарий можно только в течение 15 минут после публикации. После этого текст «замораживается».
- У отредактированного комментария ставится пометка «изменено» (`edited_at`).
- Удалить свой комментарий можно в любой момент (мягкое удаление: `is_deleted = true`, ветка ответов сохраняется).
- Модератор может удалить любой комментарий.

## Жалобы

- Пожаловаться можно на материал или на комментарий, только от своего имени.
- Автор жалобы видит только свои жалобы.
- Модераторы видят все жалобы и принимают по ним решение.
